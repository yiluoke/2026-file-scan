## 想定構成

- 文書変換：Python、Docling、Excel・Word等の形式別補完処理。
- 検索：PostgreSQL、pgvector、PGroonga、FastAPIによる検索API。
- 会話：DifyのChatflowと別途選定するLLM。外部検索APIを利用する。

## リポジトリの管理範囲

設計資料、今後作成するアプリのソース、認証情報を含まない設定・評価用コードをGitで管理する。

社内資料の原本、実データ、抽出画像、変換生成物、ログ、認証情報は会社が承認した保管先で管理する。ローカル作業用の`data/`と`artifacts/`、`.env`等はGit管理対象外とする。機密情報を含まないサンプルや評価データを将来追加する場合は、専用の管理ディレクトリを設ける。
