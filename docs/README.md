## 機能のつながり

通常の文書は `file-scan` で収集・変換します。C++・Qtのソースは `cpp-scan` で解析し、生成したMarkdownを同じ文書取込処理へ渡します。どちらもDBに登録した時点では下書きです。管理者が対象版と世代を選んで公開すると、`file-search` から根拠と出典を取得できます。

手順書を改訂したとき、検索結果はいつ切り替わるのか。3機能共通の補足資料では、手順書1件を例に、変換世代の確認、公開・差し替え、検索結果からの原本照合までを説明します。[原本・変換世代・公開版の使い方](補足/原本・変換世代・公開版の使い方.md)

新規導入では、文書取込の本番導入仕様から始めます。C++・Qtのソースを扱う環境ではソース取込の手順を、公開資料を検索する環境では検索APIの手順を続けて適用します。

DBの表を調べるときは、原本・抽出世代・チャンクは文書取込の仕様書、業務版・公開コピー・検索イベントは検索APIの仕様書を参照してください。チャット画面と利用者別のアクセス制御（ACL）は将来構想です。

## 旧資料を探すとき

整理前の資料は、当時のファイル名とフォルダ構成で保存しています。旧版のWord・図版は「説明資料」、テーブル設計やチャット構想は「設計案」、環境別の作業記録は「実装記録」からたどれます。[旧資料一式](../docs-backup-2026-11-20/) ／ [説明資料](../docs-backup-2026-11-20/explanation/README.md) ／ [設計案](../docs-backup-2026-11-20/design/) ／ [実装記録](../docs-backup-2026-11-20/implementation/) ／ [調査記録](../docs-backup-2026-11-20/research/)

旧版の全テーブル対照表とチャット画面の構想には個別の参照先があります。旧図解の参照先に `docs/design/` や `docs/implementation/` が残っている場合は、バックアップ内の同名フォルダから開いてください。[テーブル対照表](../docs-backup-2026-11-20/explanation/文書取込と検索を支えるテーブル.md) ／ [チャット画面の構想](../docs-backup-2026-11-20/design/03-llm-chat.md)
